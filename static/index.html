CBT Note は、認知行動療法（CBT）の「思考記録」をブラウザで手軽に続けられる無料Webアプリです。 登録不要、データはあなたのデバイスに保存されます。

FEATURES

CBT Note の特徴

🔒

データはあなただけのもの

入力した内容はすべてお使いのブラウザ（ローカルストレージ）に保存。外部サーバーには一切送信されません。

📋

CBTの7ステップに沿った記録

状況・気分・自動思考・根拠・反証・適応的思考・再評価の流れをウィザード形式でガイドします。

📊

気分の変化を確認

記録前後の気分レベルを比較できます。思考記録を続けることで、自分の感情パターンへの気づきが深まります。

📤

CSVで管理・バックアップ

記録はCSV形式でエクスポート・インポートが可能。大切なデータを安全に保管できます。

💻

PC・スマホどちらでも

Webアプリなのでインストール不要。PCでじっくり入力も、スマホでサッと記録も、どちらにも対応しています。

🆓

完全無料・登録不要

アカウント作成もメールアドレスの登録も不要。ページを開いてすぐに使い始められます。

HOW IT WORKS

7ステップで思考記録

①

状況

いつ・どこで・だれが関わった出来事かを記録します。

②

気分

そのときどんな気分を感じたか。気分の種類と強さ（0〜100%）を記録します。

③

自動思考

気分を感じた直前に頭に浮かんだ考えやイメージを書き出します。

④

根拠

自動思考を裏付ける客観的な事実を探します。

⑤

反証

自動思考と矛盾する事実・別の見方を書き出します。

⑥

適応的思考

根拠と反証を踏まえた、よりバランスの取れた考えを描きます。

⑦

気分の再評価

思考記録を経て、気分のレベルが変化したかを確認します。
